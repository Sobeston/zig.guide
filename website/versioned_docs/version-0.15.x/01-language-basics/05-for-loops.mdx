# For loops

For loops are used to iterate over arrays (and other types, to be discussed
later). For loops follow this syntax. Like while, for loops can use `break` and
`continue`. Here, we've had to assign values to `_`, as Zig does not allow us to
have unused values.
Ranges in Zig are defined by `0..` when they are infinite, and `0..x` when ranges are finite, including zero and x in the range.
`0..` simply means from zero to infinite. But when it is in a for loop, it means from zero to the length of the collection in the first parameter of the for loop.
